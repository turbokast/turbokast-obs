# Security policy

Please do not report vulnerabilities in public issues.

1. **Preferred:** [GitHub private vulnerability reporting](https://github.com/turbokast/turbokast-obs/security/advisories/new)
2. **Email:** security@turbokast.com

Include the affected version or commit, how to reproduce the problem and its impact. Do not include real stream keys or credentials. We will acknowledge your report, keep you updated and credit you in the advisory unless you ask us not to.

If a fix also needs a change to the hosted TurboKast service, we release both together.
